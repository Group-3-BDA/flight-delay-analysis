# Bronze to Silver Glue Job

## Purpose

Transforms raw Bronze CSV files into optimized Silver Parquet files.

## Input

Bronze S3 Bucket

## Output

Silver S3 Bucket

## Responsibilities

- Read CSV
- Apply schema
- Data Cleaning
- Convert to Parquet
- Snappy Compression
- Partition by Year
